MARKET SNIPER — Android project (prototype)
============================================

Это исходный проект Android-приложения, а не готовый APK. Он предназначен для открытия в Android Studio и сборки APK.

Функции прототипа:
- интерфейс приложения;
- выбор CSV-файла с предложениями;
- фильтр по серверу (по умолчанию Mobile 3);
- минимальная доходность и комиссия;
- поиск дешёвой продажи и высокой цены скупки;
- ручное подтверждение торговых действий.

Важно:
- Начальные карточки — демонстрационные данные, не реальные цены.
- Автоматическое подключение к Market Helper не реализовано: для этого нужен подтверждённый и разрешённый интерфейс данных.
- CSV должен содержать item/товар, price/цена и side/тип; side = sell для продажи лавкой и buy для скупки.
- Для надёжного импорта CSV используйте простые значения без запятых внутри полей.

Сборка:
1. Откройте папку проекта в Android Studio.
2. Дождитесь Gradle Sync.
3. Build > Build APK(s).
4. APK будет в app/build/outputs/apk/debug/app-debug.apk.

Требования:
- Android Studio с Android SDK 35;
- Gradle/Android Gradle Plugin, указанные в проекте.
